# The Return

This is the second chapter of the test fixture. It exists to check that narration continues from one chapter to the next.

The reader returns the following morning. The room is just as she left it. The book lies open on the table, and a thin ribbon marks the page. She sits down and begins again.

When one chapter ends, the next chapter should begin automatically. The text of the new chapter should appear, and the highlight should start with its first sentence. If a sleep timer is set to the end of the chapter, the narration should stop here instead.

The reader smiles at the familiar words. Some books are read once and forgotten. Others are read slowly, a few pages at a time, and remembered for many years.

This is the end of the test fixture.
